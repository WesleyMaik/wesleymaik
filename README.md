## 📜 A Bit About My Journey

I started programming in **2018**, initially exploring web development as a hobby, and began my professional software engineering career in **2021**.

My background was built around web engineering, from maintaining PHP and JavaScript systems to developing modern applications with **React, Next.js, TypeScript, Node.js, and cloud services**.

Over the years, I've worked across **e-commerce, SaaS, MarTech, and digital product development**, building user-facing applications, backend services, integrations, and scalable architectures.

Today, I'm increasingly focused on **AI Engineering**, exploring how LLMs, agents, intelligent automation, and modern software architecture can be combined to create better products and developer experiences.

I still care deeply about good interfaces and product experience. For me, AI is not a replacement for solid software engineering, it is another powerful layer we can use to build better software.
